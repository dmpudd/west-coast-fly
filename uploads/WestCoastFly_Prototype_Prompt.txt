Filtering logic for Explore view:
  const filtered = DATA.fisheries.filter(f => {
    const monthActivity = f.season.peak.includes(selectedMonth) ? 'peak'
      : f.season.active.includes(selectedMonth) ? 'active'
      : f.season.light.includes(selectedMonth) ? 'light' : 'off';
    if (monthActivity === 'off') return false; // hide off-season fisheries
    if (typeFilter !== 'all' && f.type !== typeFilter) return false;
    if (methodFilter !== 'all' && !f.method.includes(methodFilter === 'fly fishing' ? 'fly' : 'gear')) return false;
    return true;
  });
  Sort: peak first, then active, then light.
